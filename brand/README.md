# The dibs logo

The owner picked this one. Don't change or replace it without asking them.

- `AppIcon.icon/` is the master: the Xcode 26 Icon Composer file (a deep yellow take-a-number ticket on ink, with a short queue in red; recolored from amber at the owner's request on 2026-10-14. The app's Settings offers other colorways for the Dock). The app uses an identical copy at `app/Dibs/AppIcon.icon`.
- `dibs-icon-1024.png` is a flat render of the layers on the ink fill, for the website, README and social previews.
- `make_icon.py` is the script that drew the layer images.

A copy of this folder also lives outside the repo at `~/Documents/dibs-brand/`.
